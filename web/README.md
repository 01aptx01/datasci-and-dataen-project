# DEDS Adaptive Portfolio Risk Lab — web foundation

This folder contains the read-only D1–D2 dashboard shell and a build-time adapter for the pinned Stage 06 review snapshot. It is isolated from Python `src/` and does not import or execute the ML pipeline.

## Run locally

Requirements: Node.js 20+ and Python 3.10+. Install the development dependency with `npm install`; the frontend has no runtime npm dependencies.

```powershell
cd web
npm install
npm run build
npm test
npm run preview
```

Open `http://localhost:4173`. `npm run dev` builds the verified static snapshot and starts the same local preview server. Build output and extracted public snapshot files are ignored by Git and can be reproduced from the handoff ZIP.

## Snapshot boundary

`scripts/prepare_snapshot.py` checks the pinned outer ZIP digest, normalizes the internal and sidecar checksum files before comparing them, verifies every archived member hash, checks Evaluation/Replay IDs in the source identity and Stage 05/06 manifests, validates the exact CSV headers and status rules, then writes only:

- `forecast_audit.csv`
- `evaluation.csv`
- `dashboard_snapshot_manifest.json` (presentation metadata generated by the adapter)

The CSV data remains unchanged from the archive. No PNG, notebook, HTML report, model checkpoint, source path, or other binary is copied to the public snapshot folder. The browser verifies the CSV hashes again before parsing. Numeric data is rendered only in the recorded-session stepper, sourced from matching Test rows in the verified snapshot. Pending rows keep actual and absolute error blank.

The snapshot is a **Simulated Historical Replay**. Point-in-time source availability is unverified and report approval is pending. The app never describes the data as live.

## Routes and scope

The shell has Overview, Models, Forecasts, Portfolio, Drift, Research, Provenance, and Guide routes. Forecasts provides a read-only Recorded Session stepper over persisted Test dates. Other analytical routes show explicit next-phase empty states; D3–D5 metrics and calculations are not implemented in this D1–D2 delivery.
